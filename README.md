## Covid-19 peak hospitalisation using trajectory observer

The Covid-19 example was simulated using a user-supplied observer that tracks only the current peak number of hospitalised agents. The full trajectory is not stored.

With random seed `42` and simulation end time `100` days, the observed peak hospitalisation values were:

| Population | N | Peak hospitalised |
|---|---:|---:|
| NNJ | 589,755 | 119 |
| NDK | 5,822,763 | 1,151 |
